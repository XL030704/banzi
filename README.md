# 🎴 贵州板子 - 多人联机扑克游戏

一款基于 Web 的贵州扑克"打板子"四人联机游戏，支持手机/电脑端，无需下载安装，浏览器即可游玩。

## 🚀 远程联机配置

⚠️ **重要**：如需和朋友远程联机，请先配置 PubNub 密钥。

**快速配置**：
1. 前往 [PubNub](https://www.pubnub.com/) 用**邮箱注册**（无需 Google 账号）
2. 创建 App，获取 Publish Key 和 Subscribe Key
3. 填入 `js/network.js` 第 34-35 行

📖 **详细配置教程**：[查看 SETUP.md](SETUP.md)

## 🎮 在线体验

直接打开 `index.html` 文件即可开始游戏。

## 📋 功能特性

- ✅ **创建/加入房间** - 6位数字房间号，快速邀请好友
- ✅ **实时联机** - 基于 PubNub 技术，低延迟同步
- ✅ **完整规则** - 支持喊牌、包牌、炸弹翻倍等全部规则
- ✅ **智能提示** - 牌型自动识别，非法操作提醒
- ✅ **分数记录** - 本地存储历史战绩
- ✅ **响应式设计** - 完美适配手机/平板/电脑

## 🎯 游戏规则

### 基础信息
- 人数：4人
- 用牌：去掉大小王，共52张牌
- 发牌：每人13张
- 持有黑桃7的玩家为该局核心

### 分队规则（2v2）
1. 拿到黑桃7的人先喊牌
2. 优先喊：花色 + 2（必须是自己没有的那张2）
3. 如果自己有4张2，则改喊：花色 + A（也必须自己没有）
4. 持有被喊到那张牌的玩家，和黑桃7玩家结成一队
5. 剩下两人为另一队
6. 队友身份不能明说，只能在打牌中判断

### 包牌规则（1v3）
- 若任意玩家觉得自己牌好，可喊包牌：自己1人VS另外3人
- 赢：包牌者最先出完牌
- 输：其他3人中任意一人先出完
- 多人抢包：按黑桃7持有者逆时针顺序，靠前的优先
- 包牌局：底分×2

### 牌型大小（从大到小）
1. **连三炸弹（最大）**：3组及以上连续三张，如333444555
2. **四张炸弹**：四张相同，如AAAA
3. **滚龙**：3组及以上连续对子，如334455
4. **三张炸弹**：三张相同，如AAA
5. **普通牌型**：单张、对子、顺子（≥3张连续单牌）

**规则**：所有炸弹 > 所有普通牌型；同类型炸弹比点数：2最大，3最小；同类型牌型也比点数。压牌自愿，可压可不压。

### 出牌与收牌
- 第一轮：黑桃7玩家先出牌
- 回合：一直轮到没人能压为止
- 最后压牌的人：收走桌面上本轮所有牌，获得下一轮出牌权
- 游戏直到某一队两人都出完牌结束

### 胜负判定
**正常局（2v2）**：比较两队收牌总数，多的一方赢
- 特殊规则：第4个出完的人，他收的所有牌只能和「全场第1名」合并算总数

**双出（直接赢）**：一队两人都比对面两人先出完，直接赢，底分×2

### 翻倍规则（可无限叠加）
- 每出现1个四张炸弹 → ×2
- 每出现1个连三炸弹 → ×2
- 滚龙、三张炸弹不翻倍
- 多个则多次翻倍：×2×2×2...

### 计分规则
- 底分默认：1分
- 先把所有翻倍条件算完，得到最终分数
- 输家每个人，给赢家每个人最终分数

## 🚀 快速开始

### 方式一：直接打开（测试模式）
1. 用浏览器打开 `index.html`
2. 按 `Ctrl+T` 进入测试模式
3. 创建房间即可开始单机测试

### 方式二：多人联机
1. 一位玩家点击"创建房间"，获得6位房间号
2. 其他玩家点击"加入房间"，输入房间号
3. 4人到齐后，房主点击"开始游戏"
4. 持有黑桃7的玩家喊牌选择队友
5. 按规则出牌，直到游戏结束

## 📱 操作说明

| 操作 | 说明 |
|------|------|
| 点击手牌 | 选中/取消选中 |
| 出牌 | 选中符合规则的牌后点击"出牌" |
| 不要 | 点击"不要"跳过本轮 |
| 喊牌 | 黑桃7持有者选择花色和点数 |
| 包牌 | 点击"申请包牌"成为1v3 |
